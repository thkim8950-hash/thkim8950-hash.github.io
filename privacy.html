mail-digest

1. 수집하는 정보

Google 계정 인증으로 Gmail 읽기 전용 권한을 받아, 운영자 본인 계정에서 지정한 라벨의 메일에 한해 제목·발신 시각 등 요약에 필요한 최소 항목만 추출합니다.

2. 이용 목적

운영자 본인이 알림 메일을 한곳에서 확인하기 위한 목적으로만 사용합니다.

3. 보관과 공유

  • 메일 원문과 첨부는 저장하지 않습니다.
  • 추출한 요약 정보는 운영자가 관리하는 비공개 환경에만 보관합니다.
  • 제3자에게 판매·제공하지 않으며 광고에 사용하지 않습니다.
  • Google API에서 받은 정보의 사용은 Google API Services User Data Policy의 제한 사용(Limited Use) 요건을 따릅니다.

4. 권한 철회

Google 계정 → 타사 액세스에서 언제든 권한을 철회할 수 있습니다.

5. 문의

이 저장소의 GitHub Issues로 문의해 주세요.

English summary

This personal tool requests read-only Gmail access to the operator's own account and reads only emails in a label the operator chooses. It extracts minimal summary fields, does not store full emails, does not share data with third parties, and complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions. Contact via this repository's GitHub Issues.
